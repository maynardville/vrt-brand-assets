# VRT Brand Assets

Public brand-asset hosting for VR Theatrical email and web use.

## Brevo webfonts

Brevo stylesheet:

`https://raw.githubusercontent.com/maynardville/vrt-brand-assets/main/css/vrt-fonts.css`

The stylesheet defines:

- `Revelstoke` — Regular / 400
- `Galvji` — Regular / 400
- `Galvji` — Bold / 700

Expected font files:

- `fonts/revelstoke-regular.woff2`
- `fonts/galvji-regular.woff2`
- `fonts/galvji-bold.woff2`

## VRT email type scale

The 2021 VRT brand guide specifies Revelstoke for headlines and Galvji for body copy. It gives an 8pt minimum for digital executions but does not prescribe a complete email-specific size scale. For responsive email use, the working scale is:

- Primary headline: 36px desktop / 30px mobile — Revelstoke
- Section headline: 26px desktop / 24px mobile — Revelstoke
- Eyebrow / label: 13px — Galvji Bold
- Body: 16px — Galvji Regular
- Information block: 14px — Galvji Regular/Bold
- Button: 15px — Galvji Bold
- Footer: 12px — Galvji Regular

Fallbacks should always be provided because many email clients do not load custom webfonts.

Recommended fallback stack:

`Arial, Helvetica, sans-serif`
